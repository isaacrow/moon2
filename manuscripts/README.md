# 🌕 Moon Manuscripts MARC & RDA Cataloging System

**Comprehensive Manuscript Cataloging, Analysis & Verification Engine**

Based on:
- **MARC 21 & RDA Standards**
- **KIQP (مركز الفهرسة ونظم المعلومات) Authority Data**
- **Dromh Cataloguing Guides & Sample Datasets**
- **Liquid Glass / Apple VisionOS Interface with Moon Branding**

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Manuscript Viewer Server
```bash
node viewer_server.js
```
or run `Start_Viewer.bat`.

The viewer will be available at:
- Local: `http://localhost:3456`
- Connected with Moon Studio OPAC and linked data cataloger.
